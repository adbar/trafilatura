# AGENTS.md

Instructions for coding agents working on Trafilatura.
Read CONTRIBUTING.md first, it applies to agents too:

@CONTRIBUTING.md

## Agent rules

- Ask your user before opening, closing, commenting on or reviewing an issue or pull request, each time.
- Don't edit existing tests, `tests/evaldata.json` or `tests/eval_baseline.json` just to make a change pass. If an expected result changes on purpose, say why in the pull request.
- Run the checks listed in CONTRIBUTING.md before proposing a pull request.
