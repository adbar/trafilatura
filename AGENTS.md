# AGENTS.md

Instructions for coding agents working on Trafilatura.
Read CONTRIBUTING.md first, it applies to agents too:

@CONTRIBUTING.md

## Agent rules

- Never open, close, comment on or review issues and pull requests without your user's explicit approval for each action.
- Do not edit existing tests, `tests/evaldata.json` or `tests/eval_baseline.json` to make a change pass.
- Run the checks listed in CONTRIBUTING.md before proposing a pull request.
